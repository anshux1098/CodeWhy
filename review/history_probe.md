## Definitions

- **total commits**: every commit reachable from the default branch after a full clone.
- **reverts**: a commit whose subject starts with `Revert `, or whose body contains `This reverts commit <sha>`. Counted across the whole history, not a recent window.
- **reverts touching .py**: of those reverts, how many changed at least one `.py` file.
- **constants found**: module-level UPPER_CASE assignments and annotated assignments in `.py` files under the main package directory, whose value is a Python literal. `tests/`, `docs/`, `examples/`, `setup.py` and lowercase names are skipped, as are nested assignments.
- **commits touching line**: commits returned by `git log -G` for the constant's defining line. This is an upper bound: it also counts the introduction, file moves and reformatting, not only value changes.
- **with PR ref**: of those commits, how many reference a pull request, meaning `(#123)` in the subject or a `Merge pull request #123` subject.
