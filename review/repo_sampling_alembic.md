## Definitions

- **stated reason**: body is at least 200 characters, or contains one of: `because`, `so that`, `in order to`, `to avoid`, `due to`, `otherwise`, `trade-off`. This is a heuristic, not a verified rationale.
- **revert**: title starts with `Revert`, or body contains `This reverts commit`.
- **config-touching**: the pull request changes at least one non-lockfile path matching `*.toml`, `*.cfg`, `*.ini`, `*.yaml`, `*.yml`, `*.json`, `.env*`, `settings*.py`, `config*.py`, `constants*.py` or `defaults*.py`. Counts pull requests that touch config files, not confirmed value changes. Lockfiles ending `-lock.json` or `.lock`, and the names `package-lock.json`, `yarn.lock`, `pnpm-lock.yaml`, `poetry.lock` and `Pipfile.lock`, are excluded.
- **incident-like link**: a closing issue carries a label containing `bug`, `regression`, `security` or `crash`, or its title contains `outage`, `incident`, `regression`, `crash` or `deadlock`.
- **with review**: the pull request has at least one review.
- **median body**: median length of the sampled pull request bodies, in characters.
- **sample window**: oldest and newest `mergedAt` inside the sample, so the span each row covers is visible next to the counts. Counts are rates over this window, not over the repository's whole history.
